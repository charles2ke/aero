What changed

Latest from the agencies

Space-data services move, retire and change format. These are the changes aero now follows, reviewed against each provider's documentation or source repository on 12 November 2026.

  1. Upcoming ESA 2 Dec 2026

    Gaia Data Release 4 arrives on 2 December 2026

    ESA has scheduled Gaia DR4 for 2 December 2026. Until its tables appear in the Gaia Archive, gaia_query() keeps defaulting to gaiadr3.gaia_source; pass your own ADQL to query DR4 once it is live.

    ESA: Gaia DR4 Gaia Archive access

  2. Changed NASA 1 Dec 2026

    APOD moved to science.nasa.gov — the old API retires on 1 December 2026

    NASA moved the Astronomy Picture of the Day API to science.nasa.gov in September 2026. It needs no API key, and apod() now calls it: hdurl is the image and url the APOD post. The legacy api.nasa.gov/planetary/apod route goes offline on 1 December 2026.

    NASA: APOD migration notice api.nasa.gov

  3. Heads-up CelesTrak Jul 2026

    The satellite catalogue passed 99,999

    New objects now receive six-digit catalogue numbers, and CelesTrak's TLE output leaves them out. celestrak_elements(), station_elements() and navic_elements() request JSON (OMM) by default, which carries every object.

    CelesTrak: GP data formats SatDump issue #1221

  4. Retired NASA

    Mars Rover Photos API retired

    The Mars Rover Photos API is no longer listed on api.nasa.gov, and its source repository is archived. mars_rover_photos() now emits a DeprecationWarning; find rover imagery with image_search() instead.

    api.nasa.gov Archived repository

  5. Changed NASA

    TechPort's API moved to techport.nasa.gov

    techport_projects() and techport_project() now call techport.nasa.gov/api. Project listings require updated_since; set TECHPORT_API_TOKEN or pass techport_token to send a bearer token.

    TechPort API help

  6. New NASA · ESA

    Three new keyless data calls

    eonet_events() lists natural events from NASA EONET, image_search() searches the NASA Image and Video Library, and neocc_query() runs ADQL on ESA NEOCC's TAP service.

    EONET v3 Images API NEOCC access

  7. Changed Launch Library 2 Aug 2024

    ISRO launches now use Launch Library 2.3.0

    launches() and agency() call version 2.3.0 and its /launches/previous/ and /launches/upcoming/ routes. Anonymous access is limited to 15 requests per hour per IP address.

    2.3.0 changelog LL2 FAQ

  8. Changed ESA

    NEOCC risk list via automated download

    neocc_risk_list() fetches the daily risk list from NEOCC's automated-access service and returns it as published: pipe-delimited text. open_data_search() and open_data_dataset() are deprecated, because data.esa.int is now the ESA Data Discovery Portal and documents no public CKAN API.

    NEOCC computer access

  9. Heads-up ISS

    Open Notify is HTTP-only and unmaintained

    Open Notify has not changed since 2021 and serves plain HTTP only, so browsers block it on HTTPS pages like this one, and its crew list is maintained by hand. The ISS explorer now defaults to “Where the ISS at?”, which serves HTTPS.

    Open Notify issue #19 Where the ISS at? API

  10. Archival NASA

    InSight Mars weather is archival

    api.nasa.gov still lists the InSight weather feed, last updated in March 2021, and the mission ended in December 2022. Treat insight_weather() as historical data with gaps.

    api.nasa.gov

  11. Community ISRO

    ISRO catalogues come from a community project

    spacecrafts(), launchers(), customer_satellites() and centres() read the community-run isro.vercel.app API, last updated in January 2025. For current launches use launches(), backed by Launch Library 2.

    isro/api on GitHub

Get started

Install & use

aero needs Python 3.8 or newer and requests. Install it straight from GitHub; the aero name on PyPI belongs to an unrelated project.

  1. 1Install from GitHub

    pip install git+https://github.com/charles2ke/aero.git

  2. 2Or work from a clone

    git clone https://github.com/charles2ke/aero.git
cd aero
pip install -e .

  3. 3Calculate

    from aero import aerodynamics, atmosphere, orbital
from aero import navigation, rocketry

rho = atmosphere.density(5000)       # kg/m³ at 5 km
lift = aerodynamics.lift(rho=rho, velocity=120.0,
                         area=16.2, cl=0.4)
v = orbital.circular_orbital_velocity(
    orbital.EARTH_MU, orbital.EARTH_RADIUS + 420_000)
dv = rocketry.delta_v(rocketry.exhaust_velocity(300),
                      5500, 1500)
d = navigation.great_circle_distance(
    40.6413, -73.7781, 51.47, -0.4543)  # JFK → LHR

  4. 4Run the tests

    pip install pytest
pytest

# Optional browser tests for this website
pip install playwright
playwright install chromium
