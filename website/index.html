aero

A small Python library of common aerospace engineering calculations — from sea level to orbit.

Get started Try the calculators Try the data services

Modules

aero.atmosphere

International Standard Atmosphere model: temperature, pressure, density and speed of sound up to 20 km.

Try it with aero.atmosphere

aero.aerodynamics

Dynamic pressure, lift, drag, lift-to-drag ratio, Mach number and Reynolds number.

Try it with aero.aerodynamics

aero.orbital

Vis-viva orbital velocity, circular orbital velocity, orbital period and escape velocity.

Try it with aero.orbital

aero.rocketry

Rocket science: Tsiolkovsky rocket equation, mass ratios, propellant sizing, specific impulse, thrust, burn time, thrust-to-weight and staging.

Try it with aero.rocketry

aero.navigation

Great-circle navigation: shortest-path distance, initial and final bearings, destination and intermediate points.

Try it with aero.navigation

aero.nasa

NASA Open APIs: APOD, Mars Rover Photos, NeoWs, DONKI, EPIC, InSight weather, TechPort and the Exoplanet Archive.

Try it with aero.nasa

aero.esa

ESA services: Open Data Portal, Copernicus Data Space Ecosystem, the Gaia Archive and the NEOCC risk list.

Try it with aero.esa

aero.iss

ISS data: Open Notify position and crew, “Where the ISS at?” state vectors and TLEs, CelesTrak elements.

Try it with aero.iss

aero.isro

ISRO data: spacecraft, launchers, customer satellites, centres, Launch Library 2 launches and NavIC elements.

Try it with aero.isro

Try the data services

Pick an endpoint from any data module to build the exact request the Python client would send. Send it live from your browser, or copy the equivalent aero snippet. Services that block cross-origin calls fail in the browser; you can then choose to retry once through a public read-only CORS proxy, which sends the request URL to that third party. The retry is never offered when the request carries your own API key.

Request URLs open in a new tab. Live requests run from your browser, so some services may refuse cross-origin calls. The Python clients are not subject to that restriction.

Connecting to space agency data

Every client accepts an injectable requests.Session and timeout, and raises a module-specific error on failure.

from aero import esa, iss, isro, nasa

nasa.NASAClient().apod()                 # Astronomy Picture of the Day
esa.ESAClient().neocc_risk_list()        # Near-Earth object risk list
iss.ISSClient().current_location()       # ISS ground track point
isro.ISROClient().navic_elements()       # NavIC constellation elements

Installation & usage

pip install -e .
from aero import atmosphere, aerodynamics, navigation, orbital

rho = atmosphere.density(5000)
a = atmosphere.speed_of_sound(5000)
L = aerodynamics.lift(rho=rho, velocity=120.0, area=16.2, cl=0.4)
v = orbital.circular_orbital_velocity(orbital.EARTH_MU,
                                      orbital.EARTH_RADIUS + 400_000)
d = navigation.great_circle_distance(40.6413, -73.7781, 51.4700, -0.4543)

Run the test suite with pip install pytest then pytest.
